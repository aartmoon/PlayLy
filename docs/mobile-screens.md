# Экраны Android-приложения PlayLy

Целевые экраны MVP на Jetpack Compose. Для игры используется WebView. Точки входа в основную навигацию — **Каталог**, **Мои игры**, **Профиль**. Каталог и запуск опубликованных игр доступны гостю. Создание игр и оценки требуют входа.

| Экран                    | Что показать и что пользователь может сделать                                                                                                                                                                                                                                                                     |
|--------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Каталог**              | Поиск по названию и описанию, список опубликованных игр с автором и рейтингом. Нажатие открывает карточку игры. Пустой поиск и ошибка загрузки имеют отдельные состояния.                                                                                                                                         |
| **Карточка игры**        | Название, описание, автор, рейтинг и кнопка «Играть». Запускается опубликованная версия. Авторизованный пользователь может поставить, изменить или удалить оценку от 1 до 5. Для автора своей игры оценка скрыта.                                                                                                 |
| **Вход и регистрация**   | Email, пароль, переключение между входом и регистрацией, ошибки формы. После успеха вернуться к экрану, с которого пользователь пришёл.                                                                                                                                                                           |
| **Мои игры**             | Список своих черновиков и опубликованных игр. Нажатие открывает проект. Кнопка «Создать игру» открывает форму с названием, описанием и первым промптом.                                                                                                                                                           |
| **Проект**               | Название, описание, история версий и генераций, отметка опубликованной версии. Владелец может запустить выбранную готовую версию, изменить её промптом, опубликовать её или снять игру с публикации. Здесь же доступны правка названия и описания и удаление проекта с подтверждением.                            |
| **Создание и изменение** | При создании сохранить черновик и отправить первый промпт. При изменении показать выбранную базовую версию и поле промпта. После отправки показать состояние задания: в очереди, выполняется, готово или ошибка. При успехе открыть новую версию в проекте. При ошибке сохранить текст промпта для новой попытки. |
| **Плеер**                | Загрузка и проверка пакета выбранной версии, затем игра в WebView. Кнопка «Назад» возвращает в каталог или проект через исходную карточку. При ошибке загрузки можно повторить, при сбое игры — перезапустить. Для неподдерживаемого формата показать сообщение.                                                  |
| **Профиль**              | Email, отображаемое имя, изменение имени и выход. Гостю показать кнопку входа.                                                                                                                                                                                                                                    |

## Для интеграции

- Запуск из каталога использует `publication.versionId`, из проекта — выбранный `versionId`. Новая генерация создаёт новую версию. Опубликованная версия меняется по действию владельца.
- Отправка промпта требует `Idempotency-Key`. Прогресс читается через `GET /generations/{generationId}` до `SUCCEEDED` или `FAILED`. Готовая версия приходит в `resultVersionId`.
