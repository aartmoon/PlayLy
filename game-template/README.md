# Игровой шаблон PlayLy

«Монетки на закате» — эталонный платформер на Phaser. Он собирается из исходников в этом каталоге. Кот двигается стрелками, прыгает по пробелу и собирает монеты. На сенсорном экране доступны кнопки под сценой.

## Проверка

Понадобится Node.js 22.12 или новее. Из корня PlayLy выполните:

```sh
npm --prefix game-template ci
npm --prefix game-template run build
npm --prefix game-template run preview -- --host 127.0.0.1
```

Откройте адрес из вывода Vite, обычно `http://127.0.0.1:4173`. Соберите пять монет и нажмите «Заново». Счёт должен вернуться к нулю, а монеты появиться снова.

Сборка сначала проверяет типы TypeScript, затем записывает веб-пакет в `dist/`. Точка входа шаблона — `src/main.ts`, сцена и механики находятся в `src/CoinScene.ts`. Графика рисуется в коде. Для проверки достаточно файлов из этого каталога.

Сгенерированные игры используют общую HTML-оболочку в `runner/`. Команда запуска и два сценария ручной проверки описаны в [документации генерации](../docs/game-generation.md#3-контракт-с-моделью-и-готовые-заготовки).
